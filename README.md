## Descrição do Projeto 📌
O projeto visa apresentar um método de salvar os dados de notas fiscais em um banco de dados SQLite3.

## Funcionalidades 📝
A aplicação conta com os modos manual e automático:

- O modo manual se traduz na inserção manual de todos os dados da nota fiscal que se deseja cadastrar ✅;
- O modo automático, ao meu ver, se faz mais útil para estudo, visto que o CNPJ e nome dos fornecedores são fictícios e não possuem ligação com a realidade ✅;

## Pré-Requisitos 🔗
- [Apenas Python](https://www.python.org/downloads/), todos as bibliotecas são nativas
